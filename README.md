# random-fun-run-generator

I'm a runner trying to get in shape, and the same run over and over can get a bit stale.
I need an app to suggest/create new runs for me based on a start and ending location.
Most of the times the start and end are the same, so the run is a loop, sometimes the
run will start in one location and end in another.  I don't know if we need a substantial
database to support this app, but lets design for one to persist locations, routes, 
if we liked / loved / didn't like this particular route.  I don't know what public data
exists out there that can be used to build maps for running so that we have relatively
accurate data regarding distances.  Oh and I want to be able to specify the distance 
that I will be running, plus the preferred surface - road / sidewalk / trail, etc.
Ask me any questions
